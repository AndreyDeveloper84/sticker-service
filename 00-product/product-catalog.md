# Product Catalog v0.1

Статус: DRAFT

## P01 — Personal Sticker Pack

### Назначение
Персональный набор стикеров по фотографиям одного человека.

### Входные данные
- фотографии;
- визуальный стиль;
- тип содержимого набора;
- дополнительные пожелания при необходимости.

### Базовая конфигурация
- один человек;
- один визуальный стиль;
- один sticker pack;
- фиксированное количество стикеров;
- один preview;
- одна корректировка preview;
- финальный QC;
- выдача результата.

Рабочий ориентир MVP:
**12–16 стикеров.**

### Содержимое

#### Standard Pack
Состав определяется системой.

Пример:
- привет;
- пока;
- спасибо;
- отлично;
- нет;
- люблю;
- смеюсь;
- злость;
- удивление;
- усталость;
- работаю;
- сон;
- праздник;
- согласие;
- ожидание;
- дополнительная универсальная эмоция.

#### Custom Pack
Пользователь может задать собственные короткие фразы или идеи.

### Preview
Перед production полного набора создаётся небольшой контрольный набор изображений.

Проверяется:
- сходство;
- стиль;
- основные характеристики персонажа.

### Корректировки
В базовую стоимость входит:
**1 revision preview.**

Полная смена стиля является отдельным продуктовым действием, а не обычной корректировкой.

### Delivery
Выдача зависит от канала:
- Telegram;
- MAX.

Конкретные механизмы фиксируются в channel capability matrix и integration specification.

## P02 — Personal Avatar

### Назначение
Создание персонального аватара по фотографиям пользователя.

### Входные данные
- фотографии;
- визуальный стиль;
- дополнительные пожелания.

### Базовая конфигурация
- один человек;
- один стиль;
- несколько вариантов;
- один этап preview;
- одна корректировка;
- финальная выдача.

Рабочий ориентир:
**3 варианта.**

### Delivery
Пользователь получает готовые изображения в подходящем формате.

## Пока не фиксируется

До анализа реальных заказов не замораживаются:
- окончательная цена;
- точное количество стикеров;
- точное количество фотографий;
- финальный список эмоций;
- лимит custom-фраз;
- полный каталог стилей;
- правила дополнительных revision.
