# MAX Dialogs v0.1

Статус: DRAFT

## Основные сообщения

### MX-01 Start
Персональные стикеры и аватары по вашим фотографиям.

Кнопки: `Создать`, `Примеры`, `Мои заказы`.

### MX-03 Product
Что хотите создать?

Кнопки: `Стикерпак`, `Аватар`.

### MX-04 Style
Выберите понравившийся визуальный образ. Стиль показывается карточкой с примером.

### MX-05 Photo guide
Чтобы сохранить сходство, пришлите несколько фотографий одного человека: лицо хорошо видно, есть разные ракурсы, нормальный свет, нет сильных фильтров.

### MX-06 Upload
Показывать количество полученных фото. При достаточном комплекте разрешить продолжить.

### MX-07 Rights
Подтвердите, что это ваши фотографии или у вас есть разрешение человека на их использование для создания заказа.

Кнопки: `Подтверждаю`, `Отменить`.

### MX-08 Setup
Для стикерпака: `Универсальный набор` или `Свои фразы`. Для аватара — доступные параметры продукта.

### MX-09 Checkout
Показать продукт, стиль, количество фото, конфигурацию, число включённых корректировок и итоговую стоимость.

Кнопки: `Оплатить`, `Изменить заказ`.

### MX-10 Payment
Платёжная механика определяется отдельным MAX payment adapter. После подтверждения оплаты заказ переводится в `PAID`.

### MX-11 Accepted
Оплата получена. Сначала создаётся пробный образ для проверки сходства.

### MX-12 Preview
Проверьте образ. Нравится ли сходство и выбранный стиль?

Кнопки: `Да, всё нравится`, `Нужно поправить`.

### MX-13 Revision
Категории: `Лицо`, `Волосы`, `Телосложение`, `Цвета`, `Другое`. После выбора — короткий комментарий.

### MX-14 Production
Образ утверждён. Создаём финальный результат. Конфигурация заказа больше не меняется.

### MX-15 Ready
Показать результат и доступные способы получения. Не обещать native sticker set до подтверждения такой возможности платформой.

Кнопки зависят от delivery capability, минимум: `Скачать`, `Создать ещё`.

## Ошибки

- Payment failed: предложить повторить оплату.
- Generation failed: скрыть внутреннюю ошибку провайдера, сохранить заказ и передать в retry/operator flow.
- Delivery failed: повторять delivery, не производство.

## Клиентские статусы

Использовать те же понятные статусы, что и в Telegram: `Ждём фото`, `Ждём оплату`, `Готовим пробный образ`, `Ждём вашего решения`, `Создаём набор`, `Проверяем`, `Готово`.

Технические статусы core пользователю не показываются.
