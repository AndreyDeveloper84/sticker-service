# Telegram Screen Inventory v0.1

Статус: DRAFT

## Цель

Зафиксировать все пользовательские состояния Telegram-бота для MVP. Бизнес-логика остаётся общей с MAX; ниже описана только Telegram-поверхность.

## Важные UX-правила

1. Пользователь не видит prompt, model, generation job и внутренние статусы.
2. До оплаты показывается точный состав заказа и число включённых корректировок.
3. После оплаты сначала создаётся preview, а не полный набор.
4. Revision собирается структурированно: лицо, волосы, телосложение, цвета, другое.
5. Полная генерация запускается только после approval preview.
6. Финальная выдача выполняется только после QC.

## Telegram-specific решения

- Цифровой товар внутри Telegram оплачивается через Telegram Stars.
- Для стикерпаков целевой delivery — native Telegram sticker set, создаваемый ботом для пользователя.
- Дополнительно можно дать скачивание отдельных изображений, если это предусмотрено продуктом.
- Бот должен поддерживать `/paysupport` для вопросов по платежам.

## Не проектировать пока

- Mini App как обязательную часть MVP;
- подписки;
- реферальную программу;
- промокоды;
- произвольный prompt пользователя;
- несколько персонажей в одном заказе.
