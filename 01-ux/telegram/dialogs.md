# Telegram Dialogs v0.1

Статус: DRAFT

## Основные сообщения

### TG-01 Start
Персональные стикеры и аватары по вашим фотографиям.

Кнопки: `Создать`, `Примеры`, `Мои заказы`.

### TG-03 Product
Что хотите создать?

Кнопки: `Стикерпак`, `Аватар`.

### TG-04 Style
Выберите понравившийся визуальный образ. Стиль показывается карточкой с примером, а не техническим названием.

### TG-05 Photo guide
Чтобы сохранить сходство, пришлите несколько фотографий одного человека: лицо хорошо видно, есть разные ракурсы, нормальный свет, нет сильных фильтров.

### TG-06 Upload
Показывать количество полученных фото. Если их достаточно — разрешить продолжить; если нет — попросить добавить.

### TG-07 Rights
Подтвердите, что это ваши фотографии или у вас есть разрешение человека на их использование для создания заказа.

Кнопки: `Подтверждаю`, `Отменить`.

### TG-08 Setup
Для стикерпака: `Универсальный набор` или `Свои фразы`. Для аватара — доступные параметры продукта.

### TG-09 Checkout
Показать продукт, стиль, количество фото, конфигурацию, число включённых корректировок и итоговую стоимость.

Кнопки: `Оплатить`, `Изменить заказ`.

### TG-10 Payment
Оплата цифрового товара — Telegram Stars. Только подтверждённый successful payment переводит заказ в `PAID`.

### TG-11 Accepted
Оплата получена. Сначала создаётся пробный образ, чтобы клиент проверил сходство до полного производства.

### TG-12 Preview
Проверьте образ. Нравится ли сходство и выбранный стиль?

Кнопки: `Да, всё нравится`, `Нужно поправить`.

### TG-13 Revision
Сначала выбрать категорию: `Лицо`, `Волосы`, `Телосложение`, `Цвета`, `Другое`, затем коротко описать изменение.

### TG-14 Production
Образ утверждён. Создаём финальный результат. На этом этапе конфигурация заказа не меняется.

### TG-15 Ready
Для стикерпака: `Добавить стикерпак`, `Скачать изображения`, `Создать ещё`.

Для аватара: `Посмотреть`, `Скачать`, `Создать ещё`.

## Ошибки

- Payment failed: предложить повторить оплату.
- Generation failed: не показывать техническую ошибку провайдера; заказ остаётся в работе или передаётся оператору.
- Delivery failed: повторять только delivery, не запускать production заново.

## Клиентские статусы

Пользователю показываются понятные статусы: `Ждём фото`, `Ждём оплату`, `Готовим пробный образ`, `Ждём вашего решения`, `Создаём набор`, `Проверяем`, `Готово`.

Внутренние `GenerationJob`, retry, provider error и технические QC-коды пользователю не показываются.
