# Бот стикеров — контракт пилота v1

## Цены и каналы

| Продукт | MAX / ЮKassa | Telegram Stars |
| --- | ---: | ---: |
| 9 стикеров с надписями | 800 ₽ | 736 XTR |
| 9 стикеров без надписей | 500 ₽ | 460 XTR |
| 1 стикер | 100 ₽ | 100 XTR |

Оплата начинается сразу после подтверждения заказа. В MAX это ЮKassa в рублях, в Telegram — счёт в Stars. Каналы не конвертируют цену друг в друга во время покупки.

## Требования к готовому стикеру

- PNG или WebP;
- одна сторона ровно 512 px, вторая не больше 512 px;
- прозрачный фон;
- целевой размер файла до 512 КБ;
- без размытия и обрезанных головы, волос, рук или надписей;
- аккуратная белая обводка.

Технические параметры проверяются автоматически. Сходство, кадрирование, волосы, читаемость надписи и белая обводка остаются обязательными пунктами ручного QC.

## Целевой путь заказа

`Главное меню → вариант → стиль → фото → фразы (только для набора с надписями) → имя и контакт (необязательно: «⏭ Пропустить — свяжемся здесь») → итог → подтверждение → согласие → оплата → превью → одна правка или подтверждение → полная генерация → QC → доставка`.

Шаг «имя и контакт» показывается, но не блокирует (owner GO 2026-09-20): пропуск → в карточке «Связь: в этом чате», в консоли «Контакт для связи: в этом чате — чат Telegram @username / чат MAX id …»; введённый позже текст заменяет пропуск и валидируется как раньше.

На каждом экранном шаге есть «Назад» и «Главное меню». Главное меню не удаляет оплаченный или производимый заказ.

### Навигация без потерь (2026-09-20)

- Любое неожиданное сообщение при незавершённом заказе (текст не по запросу, стикер, документ, неизвестная команда) → «📍 Вы на шаге: …» + экран текущего шага с кнопками. Без заказа → главное меню. Бот никогда не молчит.
- При незавершённом заказе первый пункт главного меню — «▶️ Продолжить заказ #N (шаг: …)». «🎨 Заказать стикеры» при незавершённом заказе → «Продолжить текущий / Выбрать другой вариант» (фото и контакт при смене варианта сохраняются).
- После нажатия кнопки клавиатура этого сообщения снимается (best-effort). Кнопка уже пройденного шага → «Этот шаг уже пройден» + текущий экран, заказ не меняется.
- «📍 Где я?» (пункт меню, оба канала) и `/status` (Telegram): номер заказа, вариант, стиль, фото, эмоции/надписи, контакт, шаг или статус и что происходит сейчас.
- Фото, отправленное «файлом» (Telegram document с image/*, MAX file *.jpg/*.png/*.webp), принимается как фото. После каждого фото — «Фото сохранено» с кнопкой «Фото загружены»; возврат на шаг фото с уже загруженными фото показывает ту же кнопку.
